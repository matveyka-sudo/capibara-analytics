# Проверка упрощённого frontend

28 октября 2026. Ветка `codex/frontend-dashboard`. Commit/push не выполнялись.
Изменения только в `frontend/`. Презентация, модель SQL и raw не изменялись.

## Выполнено

- Убраны графики, большая обложка, KPI-панели и тёмная декоративная тема.
- Светлый интерфейс с шестью разделами и одной таблицей выбранного отчёта.
- Два блока по пять вопросов. Для вопроса 9 — отдельные срезы.
- Базовые таблицы подключены к сохранённым реальным SQL-ответам.
- Новые результаты можно открыть локально из CSV или упаковать экспортёром.
- По подробному снимку работают базовые фильтры, профиль, отмены, повторы продавца.
- Не подключённые расчёты показаны как ожидающие данные.
- Удалена библиотека Recharts, синхронно обновлён package-lock.json.

## Проверки

- TypeScript и production build проходят.
- 10 тестов проходят: расчёты и контрольные SQL-числа, нулевые месяцы,
  фильтрация до top-10, разные статусы, ошибки данных, CSV с кавычками и переносами.
- Скрипт выгрузки проходит py_compile.
- Браузер: проверены оба блока, импорт отдельного тестового CSV, два среза оплаты,
  профиль из реального топ-10 и стоимость доставки из реальных агрегатов.
- Тестовый CSV использовался только при проверке взаимодействия; после проверки
  страница перезагружена на реальные данные.

## Ограничения

В репозитории пока опубликованы только результаты вопросов 1–5. Для остальных
нужны SQL-выгрузки; frontend не придумывает ответы. Подробная выгрузка из PostgreSQL
в рамках frontend-задачи не выполнялась. Dockerfile не собирался и не запускался.
Подробная динамика/ассортимент профиля, региональная аналитика отмен, медиана/P90
задержек и рекомендации остаются зависимыми от дополнительных данных/расчётов.
