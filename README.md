# Capibara Analytics

Аналитическая база маркетплейса на PostgreSQL: модель core v3.1 и десять SQL-ответов
по продажам, покупателям, товарам, доставке, статусам, оплатам и отзывам.
Данные — [Olist](https://github.com/olist/work-at-olist-data).

Нужны Docker и Python 3.10+. Команды выполняются из корня проекта.

## Запуск

Если raw уже загружен и PostgreSQL запущен, все ответы выводятся одной командой:

```bash
python3 model/run.py --check --details
```

Если контейнер остановлен, сначала выполните `docker compose up -d postgres`.

Только для первой установки на новой базе:

```bash
bash scripts/setup.sh
python3 model/run.py --check --details
```

`setup.sh` перезагружает raw; для обычного запуска он не нужен.
`--check` сверяет контрольные значения Olist; без флага выполняются обычные проверки.
Одна команда выше выводит все ответы 1–10, включая оба отчёта Q9.
Без `--details` выводится краткая сводка по каждому вопросу.

Миграция v2.1 → v3.1 выполняется автоматически в транзакции сборки.
Q9 содержит два отчёта, поэтому сохраняется 11 CSV.
Рекомендации доступны в SQL-витрине `mart.product_recommendation`;
определение и пример запроса — в [описании модели](docs/model.md).

Результаты: `model/results/*.csv`, отчёт проверки: `model/results/validation.txt`.
По умолчанию используется контейнер `hack_postgres`; другой задаётся переменной
`ANALYTICS_PSQL_CONTAINER`. Для локального psql задайте её пустой и используйте переменные libpq.
